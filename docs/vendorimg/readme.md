# Vendor Images and Later Board Revisions

This directory contains reference images of later SDR RSP1 board revisions and
commercially offered variants derived from the original MSI.SDR design.

## Notes

The images are provided for documentation and comparison purposes. Product
appearance, PCB layout, component selection, filtering, oscillator type, and
enclosure design may vary between revisions.

These images document different implementations and revisions of the SDR RSP1
hardware. They should not be assumed to represent identical circuit designs or
component configurations.

The original image sources and associated vendor descriptions should be
consulted before drawing conclusions about technical differences between
individual revisions.
